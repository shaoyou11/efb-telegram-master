# 微信命令简化设计

## 目标

将 EFB 自动生成且难记的 `/0_reauth`、`/h_0_reauth` 和 `/extra` 收拢为稳定、中文化的微信管理入口，同时保留旧命令兼容性。

## 用户入口

- `/login`：直接获取微信登录二维码。
- `/wechat`：打开中文微信管理面板。
- `/extra`：兼容旧习惯，但改为打开微信管理面板。
- `/0_reauth`、`/h_0_reauth`：继续由原有 EFB 附加功能路由处理，不再出现在菜单和新提示中。

微信管理面板提供“重新扫码登录”“强制退出微信”“自动恢复设置”和“关闭”四项操作。强制退出必须二次确认。

## 实现边界

Telegram 主端按固定频道 ID `honus.comwechat` 查找 ComWechat，不依赖动态模块序号 `0`。登录和退出仍调用 ComWechat 已有 `reauth`、`force_logout` 附加功能，避免复制微信控制逻辑。

仅管理员可使用新入口。失败信息、等待状态、结果提示和 Telegram 命令菜单均使用中文；技术异常保留在服务日志中。

## 兼容与部署

旧命令处理器保留。ComWechat 离线提醒改为引导 `/login` 和 `/wechat`。两个源码仓库提交后，自有镜像更新固定提交并构建，NAS 部署前备份，部署后验证新入口、旧入口、二维码和容器健康状态。
